# Rakib — portfolio

A responsive, editorial-style portfolio built with plain HTML, CSS, and JavaScript. No build step or dependency install is required.

## Run locally

From this directory, start a static server:

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

Then open `http://localhost:8000`.

## Personalize

- Update the name, introduction, about copy, and links in `index.html`.
- The three illustrated case studies are explicitly presented as **self-initiated concept studies**. Edit their preview markup in `index.html` and their detail copy in `script.js` to replace them with your real work.
- Replace the GitHub links with the channels you want people to use to reach you.
- Colors, typography, layout, and responsive behavior live in `styles.css`.
